# Portfolio de propuestas inmobiliarias — Corrientes

Este repositorio contiene un portfolio central y páginas de demostración independientes para inmobiliarias de Corrientes.

## Publicación con GitHub Pages
1. Subir el contenido de esta carpeta a la rama `main` del repositorio `portfolio-inmobiliarias-corrientes`.
2. En GitHub, abrir **Settings → Pages** y seleccionar GitHub Actions como origen si no se activa automáticamente.
3. La acción de `.github/workflows/pages.yml` publicará el sitio al hacer push a `main`.
4. Revisar **Actions** para confirmar que el despliegue terminó correctamente.

## Importante
- Las demostraciones son propuestas conceptuales independientes, no sitios oficiales de las inmobiliarias.
- Los datos del directorio son preliminares y deben confirmarse antes de usarlos comercialmente.
- Las fotografías ilustrativas no representan propiedades anunciadas por estas inmobiliarias.
- La publicación en internet de una foto no significa que sea de dominio público. Incorporar fotos de propiedades reales solo cuando la licencia o autorización permita su uso comercial y edición.
- No se inventan anuncios, precios, reseñas ni características de inmuebles.
